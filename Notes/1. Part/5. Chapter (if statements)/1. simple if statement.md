
At the heart of every if statement is an expression that can be evaluated as
True or False and is called a conditional test

Python executes the code following the if
statement. If the test evaluates to False, Python ignores the code following
the if statement.

```python
cars = ['audi', 'bmw', 'subaru', 'toyota']
for car in cars:
if car == 'bmw':
	print(car.upper())
else:
	print(car.title())
```
