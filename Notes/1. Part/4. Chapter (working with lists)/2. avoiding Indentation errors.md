Python uses indentation to determine when one line of code is connected to
the line above it.
- it uses whitespace to force you to write neatly formatted code with a clear visual structure. 
- If you forget indentation, Python will remind you

If you accidentally indent a line that doesn’t need to be indented, Python
informs you about the unexpected indent

take a note that colon is put always before a following indentation
- remember to put them in there

example of proper indentation
```python
magicians = ['alice', 'david', 'carolina']
for magician in magicians
	print(magician)

```
