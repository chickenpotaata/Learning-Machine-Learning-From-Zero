Many reasons exist to store a set of numbers. For example, you’ll need to
keep track of the positions of each character in a game, and you might want
to keep track of a player’s high scores as well. 
- Lists are ideal for storing sets of numbers,


Using the range() Function to create new printable values
```python
for value in range(1,5):
	print(value)
```

using range to create new list consisting of range
```python
# take a note that we need to convert the range output to a list
numbers = list(range(1,6))
print(numbers)
```
