
you can slice lists and process only part of all the values

```python 
players = ['charles', 'martina', 'michael', 'florence', 'eli']
print(players[0:3])

# this will print
# ['charles', 'martina', 'michael']
```

# Looping Through a Slice
works the same way as working through full lists
```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']
print("Here are the first three players on my team:")
for player in players[:3]:
	print(player.title())
```
