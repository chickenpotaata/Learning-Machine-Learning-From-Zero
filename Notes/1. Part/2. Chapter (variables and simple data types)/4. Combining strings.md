the method of combining strings is called concatenation

```python
first_name = "ada"
last_name = "lovelace"

u full_name = first_name + " " + last_name
print(full_name)
```

this will output
```python
ada lovelace
```


You can use concatenation to compose a message and then store the
entire message in a variable
```python
u message = "Hello, " + full_name.title() + "!"
print(message)
```
