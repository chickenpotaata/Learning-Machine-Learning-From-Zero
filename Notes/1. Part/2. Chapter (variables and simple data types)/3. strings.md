Strings are quite simple at first glance, but you can use them in many different ways.


## changing case in a string with methods

```python
name = "ada lovelace"

print(name.title())
```
this will print
```cmd
Ada Lovelace
```

---

```python
name = "Ada Lovelace"
print(name.upper())
print(name.lower())
```
this will print
```
ADA LOVELACE
ada lovelace
```
