we need different means of handling this list data to actually have anything meaningful to be used
## modifying
```python
motorcycles = ['honda', 'yamaha', 'suzuki']
print(motorcycles)
motorcycles[0] = 'ducati'
print(motorcycles)
```
this code takes the motorcycles element honda and replaceds it with ducati
- technically it wont even take that value, simply overwrites the list position with the new value


## adding
```python
motorcycles = ['honda', 'yamaha', 'suzuki']
print(motorcycles)

u motorcycles.append('ducati')
print(motorcycles)
```
this outputs
```
['honda', 'yamaha', 'suzuki']
['honda', 'yamaha', 'suzuki', 'ducati']
```

we can insert values into specific positions with insert() method

for example inserting item to the start of the list
```python
motorcycles.insert(0, 'ducati')
print(motorcycles)
```


## removing
you can use the del statement to delete element from list completely
```python
motorcycles = ['honda', 'yamaha', 'suzuki']
print(motorcycles)

del motorcycles[0]
print(motorcycles)
```

will print
```
['honda', 'yamaha', 'suzuki']
['yamaha', 'suzuki']
```

you can also remove and return the value of the removed item from list with pop() method
```python
motorcycles = ['honda', 'yamaha', 'suzuki']
print(motorcycles)

popped_motorcycle = motorcycles.pop()
print(motorcycles)
print(popped_motorcycle)
```

we can also pop() items from any position of an list
- in the next example we pop the first item of a list
```python
first_owned = motorcycles.pop(0)
```
