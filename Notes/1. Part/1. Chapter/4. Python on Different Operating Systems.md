## Linux
Linux systems are designed for programming, so Python is already installed
on most Linux computers.

To find out whether Python is installed, enter python

if you want to run python3, just specify the 3 at the end, without spaces

example
```bash
$ python3
Python 3.5.0 (default, Sep 17 2015, 13:05:18)
[GCC 4.8.4] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>
```
