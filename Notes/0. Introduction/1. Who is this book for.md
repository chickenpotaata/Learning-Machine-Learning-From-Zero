Python Crash Course is written for people of any age who have never programmed in Python before or have never programmed at all.

## what can you expect to learn ? 
The purpose of this book is to make you a good programmer in general
and a good Python programmer in particular. You’ll learn efficiently and
adopt good habits as I provide you with a solid foundation in general pro-
gramming concepts.

The first part of the book is about learning basic programming concepts
- how to store data on different ways
- working through datasets by using different methods and means
- You’ll learn to use while and if loops to test for certain conditions so you can run specific sections of code while those conditions are true and run other sections when they’re not

in the second part of the book you apply what you learned in part 1
- by applying it on 3 different projects
- first project is space-invaders style shooting game
- second project is data visualization project working through datasets with matlib
- third project is about building small web application called learning log
