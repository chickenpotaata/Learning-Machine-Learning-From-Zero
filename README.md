# Machine Learning Roadmap 📚

Welp... I decided to start learning machine learning from zero.

This repository contains my notes, implementations, exercises, and projects as I work through books.

## 🎯 Goals

- Build a strong mathematical foundation for machine learning.
- Understand the theory behind common ML algorithms.
- Implement models and algorithms using Python.
- Develop practical machine learning and deep learning projects.

## 🗺️ Learning Roadmap

### 1. Python & Data Analysis
- [ ] **[Python Crash Course](https://nostarch.com/python-crash-course-3rd-edition)** — Eric Matthes

**Focus:** Python fundamentals, NumPy, pandas, data manipulation, visualization, and Jupyter notebooks.

### 2. Mathematics & Statistics
- [ ] **[Mathematics for Machine Learning](https://mml-book.github.io/)** — Deisenroth, Faisal & On

**Focus:** Linear algebra, calculus, probability, statistics, and optimization.

### 3. Classical Machine Learning
- [ ] **[An Introduction to Statistical Learning (Python)](https://www.statlearning.com/)** — James, Witten, Hastie, Tibshirani & Taylor

**Focus:** Regression, classification, decision trees, ensembles, SVMs, clustering, model evaluation, and feature engineering.

### 4. Practical ML
- [ ] **[Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow]** — Aurélien Géron

**Focus:** Statistical learning theory, Bayesian methods, probabilistic modeling, and advanced algorithms.

### 5. Deep Learning
- [ ] **[Deep Learning](https://www.deeplearningbook.org/)** — Goodfellow, Bengio & Courville

**Focus:** Neural networks, backpropagation, optimization, CNNs, attention, and generative models.

### 6. Production ML & Specialization
- [ ] **Designing Machine Learning Systems** — Chip Huyen
- [ ] **Build a Large Language Model (From Scratch)** — Sebastian Raschka

**Focus:** ML deployment, monitoring, LLMs, transformers, reinforcement learning, and NLP.
